# html-test

A repository for testing HTML elements and functionality.

## Files

- `draft.html` - A comprehensive draft page for testing various HTML elements including:
  - Semantic HTML structure
  - CSS styling and layout
  - Form elements and interactions
  - Tables and data presentation
  - Navigation and accessibility features

## Usage

To view the draft page, open `draft.html` in a web browser or serve it using a local HTTP server:

```bash
python3 -m http.server 8000
```

Then navigate to `http://localhost:8000/draft.html`
